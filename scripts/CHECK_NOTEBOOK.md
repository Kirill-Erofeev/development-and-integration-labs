# Проверка исходного notebook практики 1

`check_notebook.py` выполняет пять заранее прочитанных и проверенных ячеек
`source_experiment.ipynb`: импорты, обучение Iris, оценку accuracy, сохранение
`model.pkl` и прогноз по разрешённому `data_sample/sample.csv`.
Скрипт не зависит от `app/` или `src/` и подходит для начального этапа проекта.
Нужен глобальный Python 3.11 и установленные зависимости notebook.

Запуск из корня репозитория:

```powershell
py -3.11 -X utf8 scripts/check_notebook.py `
  --notebook "Семинар 04.09.2026/notebooks/source_experiment.ipynb" `
  --input data_sample/sample.csv `
  --work-dir .verification/notebook-run
```

Если сохранён доверенный артефакт итогового проекта, добавьте
`--reference-model models/model.pkl`. Коэффициенты, intercept, классы, число и
порядок признаков, имена классов будут сопоставлены без перезаписи эталона.
Без этого параметра helper не читает модель итогового проекта.

Рабочий каталог должен быть новым и находиться внутри `.verification/` текущего
репозитория. В него копируется только разрешённый `sample.csv`; notebook создаёт
там отдельный `model.pkl`. Повторное использование существующего каталога запрещено,
автоматической очистки нет. Для следующего запуска задайте новое имя каталога.
Исходный CSV, notebook и `models/model.pkl` не изменяются.

Печатаются номера ячеек и их исходный stdout. Проверка требует
`accuracy=0.9473684210526315`, класс `0`, имя `setosa` и созданный `model.pkl`.

Это выполнение доверенного Python-кода, а не изолированная среда для чужих notebook.
Helper принимает только пять известных исходных ячеек: их SHA-256 закреплены
в `REVIEWED_CELL_HASHES`, переносы CRLF нормализуются в LF, внешние пробелы убираются.
При изменении любого кода проверка останавливается до копирования CSV и выполнения.
Изменять список допустимых хешей следует только после отдельного чтения и проверки
всех обновлённых ячеек. Чужие notebook, иные CSV и pickle не поддерживаются.
Пути с symlink, junction или другими Windows reparse points отклоняются.

accuracy `0.9473684210526315`, прогноз `0 / setosa`, точное совпадение коэффициентов,
intercept, классов и метаданных. Отдельная модель сохранена в
`.verification/notebook-check-20261004/model.pkl`.
Три дополнительные проверки подтвердили отказ для существующего рабочего каталога,
каталога вне `.verification` и другого входного файла до выполнения ячеек.
