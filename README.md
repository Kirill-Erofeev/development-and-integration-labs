## Практическая работа 1: структура ML-проекта

Проект преобразует выданный исследовательский notebook с классификацией Iris
в отдельные команды обучения и предсказания.

### Исходные материалы

- `Семинар 04.09.2026/Практика 1 - Структура репозитория ML-проекта.docx` — условие практической работы.
- `Семинар 04.09.2026/Описание_заготовки.md` — описание исходной заготовки.
- `Семинар 04.09.2026/Заготовка_для_практики_1.zip` — неизменённый исходный архив преподавателя.
- `Семинар 04.09.2026/notebooks/source_experiment.ipynb` — исходный эксперимент без результатов выполнения.

Архив и документы остаются в корне семинара. Репозиторий находится в папке
предмета и объединяет все лабораторные работы; для публикации выбран GitHub.

### Карта переноса

| Часть notebook | Итоговый файл |
| --- | --- |
| Загрузка Iris, разделение выборки, обучение, оценка и сохранение | `src/train.py` |
| Чтение контрольного примера, загрузка модели и предсказание | `src/predict.py` |
| Имена признаков и пути по умолчанию | `src/common.py` |
| Проверка результата и обработки ошибочного входа | `tests/test_predict.py` |

Параметры исходника: `test_size=0.25`, `random_state=42`, `max_iter=300`,
стратифицированное разделение выборки. Они сохраняются значениями по умолчанию.

Исходный дефект: `sample.csv` и `model.pkl` разрешаются относительно текущего
рабочего каталога. В итоговом проекте стандартные пути будут вычисляться от
расположения кода, а явно переданные относительные пути — от каталога запуска.

### Проверка исходной заготовки

Пять кодовых ячеек выполнены последовательно через Python 3.11.9 из каталога
`data_sample/`. Получены `accuracy=0.947`, класс `0` и имя `setosa`.
При выполнении исходной ячейки предсказания из другого каталога воспроизведён
`FileNotFoundError` для `sample.csv`. Очищенный notebook сохраняет исходный код
для сравнения; рабочая реализация будет находиться в `src/`.

Ход выполнения и проверки перечислены в [PLAN.md](<Семинар 04.09.2026/PLAN.md>).
