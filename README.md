## Практическая работа 1: структура ML-проекта

Цель работы — перенести исследовательский эксперимент классификации Iris
в воспроизводимый проект с отдельными командами обучения и предсказания,
сохранённой моделью, проверками входных данных и автоматическими тестами.
Исследовательский код остаётся в notebook для сравнения с реализацией в `src/`.

### Запуск

Все команды этого раздела выполняются из корня репозитория.
Для работы принято использовать глобальный Python 3.11 без `.venv`.
Исходный эксперимент проверен на Python 3.11.9.

В Windows:

```powershell
py -3.11 -m pip install -r requirements.txt
py -3.11 src/train.py
py -3.11 src/predict.py
py -3.11 src/predict.py --output-format text
py -3.11 -m pytest
```

Эквивалентные команды для POSIX при наличии `python3.11`:

```sh
python3.11 -m pip install -r requirements.txt
python3.11 src/train.py
python3.11 src/predict.py
python3.11 -m pytest
```

Запуск на Linux и установка в чистое окружение не проверялись.
Версии `scikit-learn==1.7.2` и `joblib==1.5.2` сохранены из заготовки;
для тестов используется `pytest==8.4.2`. Точные версии остальных зависимостей
перечислены в [requirements.txt](requirements.txt).

Поддерживается запуск как модулей: `py -3.11 -m src.train`
и `py -3.11 -m src.predict` из корня репозитория.

### Команды и пути

| Команда | Параметр | Значение по умолчанию |
| --- | --- | --- |
| `src/train.py` | `--model-path` | `models/model.pkl` |
| `src/train.py` | `--test-size` | `0.25` |
| `src/train.py` | `--random-state` | `42` |
| `src/train.py` | `--max-iter` | `300` |
| `src/predict.py` | `--model-path` | `models/model.pkl` |
| `src/predict.py` | `--input` | `data_sample/sample.csv` |
| `src/predict.py` | `--output-format` | `json`; также доступен `text` |

Стандартные пути вычисляются в `src/common.py` от `__file__`, поэтому
не зависят от рабочего каталога. При запуске из другого каталога укажите
абсолютный путь к самому скрипту. Явно переданные относительные значения
`--model-path` и `--input` разрешаются относительно каталога запуска.
Обучение создаёт каталог назначения, если его ещё нет.

Справка доступна через `py -3.11 src/train.py --help`
и `py -3.11 src/predict.py --help`.

### Вход, артефакт и результат

Вход предсказания — CSV в UTF-8 с разделителем-запятой и заголовком
из четырёх уникальных колонок:
`sepal_length`, `sepal_width`, `petal_length`, `petal_width`.
Колонки можно переставлять; скрипт восстановит порядок признаков модели.
Допускаются несколько объектов и завершающие пустые строки.
Каждая строка объекта должна содержать четыре конечных числовых значения.
Пустой набор, пропуски, лишние или повторяющиеся колонки, нечисловые значения,
`NaN` и бесконечности отклоняются.

`train.py` загружает Iris, выполняет стратифицированное разделение,
обучает `LogisticRegression` и сохраняет через `joblib` словарь:

- `model` — обученный классификатор;
- `feature_columns` — список признаков в порядке обучения;
- `target_names` — список имён классов.

Исходный notebook сохраняет в `model.pkl` только классификатор.
Этот формат отличается от итогового: артефакт для `predict.py` необходимо
создавать через `train.py`. Предсказание загружает модель и метаданные,
не вызывает `fit` и не читает Iris для получения имён классов.

Формат вывода `predict.py`: JSON по умолчанию; `--output-format text` включает текстовый вывод.
Результаты направляются в stdout, диагностика ошибок — в stderr.
В JSON возвращается список, по одному объекту на входную строку,
с полями `predicted_class` (целое число) и `predicted_name` (строка).
В текстовом формате каждому объекту соответствует строка
`predicted_class=0 predicted_name=setosa`. Порядок объектов сохраняется.
Неизвестный формат отклоняется с кодом `2` до загрузки модели.
Ошибки входных данных, отсутствующих файлов и неподходящего формата артефакта
сообщаются в stderr с кодом завершения `2`, без traceback.

Параметры исходника сохранены: `test_size=0.25`, `random_state=42`,
`max_iter=300` и стратификация. Все пять кодовых ячеек исходного notebook

`data_sample/`: точность составила `0.9473684210526315`,
предсказаны класс `0` и имя `setosa`.

с рабочим каталогом `data_sample/`. Notebook сохраняет исследовательский код
без результатов выполнения. `jupyter` не входит в обязательные зависимости;
для команд обучения, предсказания и тестов он не требуется.

### Ограничения

Модель учебная; полученная точность относится к выбранному разделению Iris.
Проверка окружения ограничена глобальным Python по принятому решению;
чистое окружение для этой работы не создаётся.

Через `joblib` следует загружать только собственный или доверенный артефакт
с теми же версиями зависимостей, что использовались при обучении.
Причины — возможность выполнения кода при загрузке и отсутствие гарантии
совместимости между версиями; см. [официальную документацию scikit-learn 1.7](https://scikit-learn.org/1.7/model_persistence.html)
(сверено 11 сентября 2026 года).
