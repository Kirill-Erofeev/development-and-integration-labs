# Разработка и интеграция

Единый проект лабораторных работ и зачёта по дисциплине. Платформа — GitHub, Python — 3.11. Исходный код проекта размещается в корне репозитория.

Материалы находятся в папках семинаров. Каждый этап содержит реализацию, проверки и снимки фактических результатов. Word-отчёты добавляются отдельными завершающими коммитами после подготовки пользователем.

Проверочные копии и инструменты общего проекта размещаются в `.verification` корня дисциплины. Снимки и протоколы каждой работы сохраняются в папке соответствующего занятия.
