# План выполнения практик 2–4

## Действующие решения

- Один репозиторий `development-and-integration-labs`, GitHub вместо GitVerse.
- Код развивается в корне репозитория, задания и результаты этого занятия — здесь.
- Глобальный Python 3.11, без отдельных виртуальных окружений.
- Word-отчёты отменены; учебное review согласовано.
- Документы и архивы остаются в корнях семинаров и не игнорируются.
- Ранее разрешённые учебные CSV используются только в согласованных пределах; разрешение на локальную работу не означает разрешения на публикацию или клонирование новых копий.
