# Практика 2 — Git и коллективная разработка

## Требование и реализация

Ветка этапа — `replay-20261005/lab-02-git`. CLI получает параметр `--output-format`
со значениями `json` и `text`; JSON сохраняется по умолчанию. Изменение
затрагивает форматирование stdout, а не данные модели или алгоритм прогноза.

```powershell
py -3.11 src/predict.py
py -3.11 src/predict.py --output-format json
py -3.11 src/predict.py --output-format text
py -3.11 src/predict.py --output-format yaml
py -3.11 -m pytest -q
```

Ожидаются одинаковые класс `0` и имя `setosa` в JSON и текстовом виде.
Неизвестный формат `yaml` должен дать код `2` и диагностику в stderr до инференса.

## Реальный учебный конфликт

Конфликт воспроизводится на одной строке корневого README в двух ветках от
общего родителя. Базовая строка:

```text
Вывод CLI: JSON поступает в stdout.
```

В одной ветке уточняется наличие текстового формата, в другой — назначение stderr.
Обычный merge должен действительно остановиться с конфликтом. Снимок состояния
включает `git status`, конфликтную строку и маркеры, а не заранее нарисованный пример.
Решение объединяет оба уточнения:

```text
Вывод CLI: JSON используется по умолчанию, --output-format text включает текст; диагностика поступает в stderr.
```

После правки проверяются отсутствие маркеров, diff, CLI и pytest; затем фиксируется
merge commit. Итоговый граф должен иметь два родителя у коммита разрешения.
Названия двух вспомогательных веток, их новые SHA и SHA merge записываются
по факту в CHECKS.md. Старые SHA и ранее проведённые конфликты сюда не переносятся.

```powershell
git status --short
git diff --check
git log --graph --oneline --decorate -12
```

## Саморазбор и pull request

В PR описываются сохранение JSON по умолчанию, новый текстовый формат и фактические
проверки. Саморазбор является учебным: автор проверяет интерфейс, ошибки, тесты,
документацию и разрешение конфликта. Он не выдаётся за отзыв независимого коллеги
или одобрение другого аккаунта. Результат саморазбора и фактическое исправление
отражены в [CHECKS.md](CHECKS.md).
